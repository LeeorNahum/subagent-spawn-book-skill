# Claude Sonnet 5

## Spawn

Claude Code CLI is Claude Sonnet 5's native harness. Use low effort for wording, naming, and creative variation passes. Use medium effort for higher-taste implementation work.

```text
claude -p --model "claude-sonnet-5" --effort low --dangerously-skip-permissions --name "<session name>" "<task prompt>"
```

If the current harness is Claude Code and exposes internal Claude Sonnet 5 subagent tooling, use that instead of the command.
